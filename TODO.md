Этапы разработки ядра типа Linux:

1. **Определить архитектуру**  
    Выбрать модель ядра: монолитное, микроядерное или гибридное. Linux — монолитное модульное ядро.
    
2. **Подготовить загрузку**  
    Написать bootloader или использовать GRUB. Ядро должно уметь запускаться после загрузчика.
    
3. **Сделать минимальный kernel entry**  
    Точка входа ядра: инициализация стека, переход в защищённый/long mode, базовый вывод текста.
    
4. **Управление памятью**  
    [[MM]]
    Реализовать:
    - физический аллокатор страниц;
    - виртуальную память;
    - таблицы страниц;
    - heap для ядра.
5. **Обработка прерываний**  
    Настроить IDT/GDT, обработчики исключений CPU, IRQ, таймер, клавиатуру.
    
6. **Планировщик процессов**  
    Реализовать задачи/потоки, переключение контекста, приоритеты, sleep/wakeup.
    
7. **Системные вызовы**  
    Создать интерфейс между пользовательскими программами и ядром: `read`, `write`, `fork`, `exec`, `exit` и т.д.
    
8. **Драйверы устройств**  
    Начать с простых:
    
    - VGA/Framebuffer;
        
    - клавиатура;
        
    - таймер;
        
    - диск;
        
    - PCI/USB позже.
        
9. **Файловая система**  
    Сначала простая RAMFS или initrd, затем ext2/ext4-подобная система.
    
10. **User space**  
    Добавить пользовательский режим, запуск первых программ, shell, libc или минимальную runtime-библиотеку.
    
11. **Модули ядра**  
    Сделать возможность загружать и выгружать драйверы без пересборки ядра.
    
12. **Сеть**  
    Реализовать сетевые драйверы, Ethernet, ARP, IP, ICMP, UDP, TCP.
    
13. **Безопасность**  
    Права пользователей, изоляция процессов, permissions, capabilities, sandboxing.
    
14. **Отладка и тестирование**  
    Использовать QEMU, GDB, логирование, kernel panic, unit-тесты для подсистем.
    
15. **Оптимизация и переносимость**  
    Поддержка разных архитектур, SMP, многопоточность, энергосбережение, производительность.

Минимальный порядок для учебного ядра:

`boot → вывод текста → память → прерывания → таймер → процессы → syscall → файловая система → user space`.
