Получение карты памяти — это первый реальный шаг работы с RAM, и он зависит от того, **как загружается твоё ядро**. Сам ты напрямую «спросить BIOS» уже не можешь (после перехода в protected/long mode), поэтому это делает **загрузчик** и передаёт тебе.

Разберём практично 👇
# 1. Через загрузчик (самый нормальный способ)

## ✔ Вариант A: Multiboot (GRUB)

Если ты используешь GRUB — он уже всё делает за тебя.

### Что происходит:

GRUB передаёт ядру структуру `multiboot_info`, где есть карта памяти.

---

## 📦 Структура (упрощённо):

```c
struct multiboot_info {
    uint32_t flags;
    uint32_t mmap_length;
    uint32_t mmap_addr;
};
```

---

## 📦 Запись карты памяти:

```c
struct multiboot_mmap_entry {
    uint32_t size;
    uint64_t addr;   // начало области
    uint64_t len;    // длина
    uint32_t type;   // тип
};
```

---

## Типы:

* `1` → доступная RAM ✅
* `2` → зарезервировано ❌
* другие → ACPI, устройства и т.д.

---

## 🔧 Как использовать:

```c
for (entry = mmap_addr; entry < mmap_addr + mmap_length; ) {
    if (entry->type == 1) {
        // это свободная память
    }
    entry = (void*)entry + entry->size + sizeof(entry->size);
}
```

---

# 🔹 2. Через BIOS (если пишешь свой bootloader)

Если ты не используешь GRUB, тогда:

## Используется:

👉 **BIOS interrupt 0x15, функция E820**

---

## В реальном режиме:

```asm
mov eax, 0xE820
mov edx, 0x534D4150 ; "SMAP"
mov ecx, 24
mov ebx, 0
int 0x15
```

BIOS возвращает одну запись за раз → нужно вызывать в цикле.

---

## 📦 Структура:

```c
struct e820_entry {
    uint64_t base;
    uint64_t length;
    uint32_t type;
};
```

---

## Важно:

* работает **только в real mode**
* потом ты должен сохранить результат и передать в ядро

---

# 🔹 3. Через UEFI (современные системы)

Если ты используешь UEFI:

## Используется:

👉 `GetMemoryMap()`

---

## Пример (упрощённо):

```c
EFI_MEMORY_DESCRIPTOR *map;
UINTN map_size;

BootServices->GetMemoryMap(&map_size, map, ...);
```

## Типы:

* `EfiConventionalMemory` → свободная память
* `EfiReservedMemoryType` → занято

# Что делать дальше

После получения карты памяти ты:

### 1. Фильтруешь:

оставляешь только:

```text
type == usable
```

### 2. Делишь на страницы:

обычно по 4KB:

```text
[addr → addr + len] → разбиваешь на страницы
```

### 3. Передаёшь в PMM:

например:

```c
init_pmm(memory_map);
```

# Типичная ошибка новичков

 Использовать всю память подряд
 Игнорировать занятые области
 Перезаписать своё же ядро

# Минимальный пример логики

```c
if (region.type == USABLE) {
    for (addr = region.start; addr < region.end; addr += 4096) {
        mark_page_free(addr);
    }
}
```

# Важный момент

Ты **обязан исключить**:
* память, где лежит ядро
* стек
* таблицы страниц
* mmap структура
